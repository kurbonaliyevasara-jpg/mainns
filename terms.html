Xizmat ko'rsatish shartlari (Terms of Service)

Oxirgi yangilanish: 24-Iyul, 2026-yil

1. Shartlarning qabul qilinishi

Ushbu ilovadan foydalanish orqali siz mazkur Xizmat ko'rsatish shartlariga to'liq rozilik bildirasiz. Agar siz shartlarga rozi bo'lmasangiz, ilovadan foydalanmang.

2. Xizmat tavsifi

Bizning ilovamiz Instagram Graph API orqali foydalanuvchilarning professional akkauntlaridagi kommentariyalarni avtomatlashtirish, tahlil qilish va ularga tezkor javob yuborish xizmatlarini taqdim etadi.

3. Ma'lumotlar xavfsizligi va foydalanish

Ilova Meta API orqali faqatgina foydalanuvchi ruxsat bergan ma'lumotlar (kommentariyalar va media postlar) bilan ishlaydi. Biz foydalanuvchilarning shaxsiy ma'lumotlarini uchinchi tomonlarga sotmaymiz va noqonuniy foydalanmaymiz.

4. Foydalanuvchining majburiyatlari

  • Taqdim etilgan API tokenlar va ilova sozlamalari maxfiyligini saqlash.
  • Ilovadan Instagram va Meta qoidalariga zid bo'lmagan tarzda (spam yozmaslik, haqoratli so'zlar ishlatmaslik) foydalanish.

5. Mas'uliyatni cheklash

Biz ilova faoliyatidagi uzilishlar yoki Meta API tizimidagi o'zgarishlar tufayli yuzaga keladigan vaqtinchalik muammolar uchun javobgarlikni zimmamizga olmaymiz.

6. Aloqa

Savollar bo'yicha biz bilan bog'lanish uchun o'z aloqa kanallaringizdan foydalanishingiz mumkin.
